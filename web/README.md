# 허스키 메이커 — 웹 2D 픽셀 버전

브라우저에서 도는 2D 픽셀 아트 버전입니다. 지금은 **1단계: 아기 허스키 그림과 애니메이션 미리보기**입니다. 교감 시스템(손 커서·손짓·유대·AI·훈련)은 그림이 확정된 뒤 붙입니다.

## 실행

빌드 없이 정적 서버로 `web/` 폴더를 띄우고 `index.html`을 엽니다.

```sh
cd web
python3 -m http.server 8000      # 또는: npx serve .
```

- 커서를 움직이면 고개가 따라오고, 강아지를 클릭하면 쓰다듬기 반응, 같은 곳을 다시 누르면 긁어 주기, 꼬리를 누르면 움찔합니다.
- 아래 버튼으로 동작 15종을 재생하고, 기분 슬라이더로 꼬리 속도를, 속도 0.25×로 프레임을 천천히 볼 수 있습니다.
- 카메라 1.5×/2×는 강아지를 따라가며 확대합니다. "모든 동작 한눈에"는 전 동작을 격자로 동시에 재생합니다.

## 구조

| 경로 | 역할 |
| --- | --- |
| `src/engine/raster.js` | 순수 JS 픽셀 래스터(DOM 없음). 브라우저·Node 도구·테스트가 같은 코드로 그림 |
| `src/engine/screen.js` | 480×270 버퍼를 정수 배율로 확대해 캔버스에 표시, 카메라 확대 |
| `src/engine/loop.js` | 고정 시간 간격(1/60초) 루프, 느리게 보기 |
| `src/engine/fx.js` | 하트·Zzz·물방울 같은 효과 |
| `src/art/palette.js` | 한 글자 = 한 색 팔레트 |
| `src/art/puppy.js` | 아기 허스키 부위 스프라이트(텍스트 격자) |
| `src/art/fx.js` | 효과·손 커서 스프라이트 |
| `src/art/room.js` | 거실 배경(절차적으로 그림) |
| `src/anim/rig.js` | 부위 조립(자세, 머리 종류별 눈·귀·입 위치), 부위 판정 |
| `src/anim/clips.js` | 애니메이션 클립과 자세 전환 규칙 |
| `src/anim/animator.js` | 클립 재생 + 숨쉬기·깜빡임·귀 쫑긋·꼬리·시선 레이어 |
| `src/preview.js` | 미리보기 페이지 |

## 스프라이트 작성 규칙

스프라이트는 문자열 배열로 씁니다. 한 글자가 한 픽셀이고 `.`은 투명, 나머지 글자는 `palette.js`의 색입니다. 모든 행은 길이가 같아야 하고, `anchor`는 부위가 붙는 관절 픽셀입니다.

- 오른쪽을 보는 모습으로만 그립니다. 왼쪽은 리그가 기준점 기준으로 뒤집습니다.
- 먼 쪽 다리·귀는 따로 그리지 않고 리그가 어둡게 칠합니다.
- 픽셀 아트는 회전하면 깨지므로, 각도가 다른 모습(위·아래·정면 머리, 다리 앞뒤)은 각각 그립니다.

## 도구 (Node, 의존성 없음)

```sh
node tools/sheet.mjs out.png 8           # 모든 스프라이트를 확대한 시트
node tools/poses.mjs out.png 6           # 자세 샘플
node tools/scene.mjs out.png 3           # 방 + 강아지
node tools/clips.mjs outDir --gif        # 클립 연속 사진 + 클립별 GIF (ffmpeg 필요)
node tools/build-artifact.mjs out.html   # 미리보기를 단일 HTML로 묶기 (npx esbuild)
```

## 테스트

```sh
cd web && npm test     # node --test tests/*.test.js
```

스프라이트 형식, 기준점, 좌우 반전, 모든 클립이 참조하는 부위 존재·양방향 렌더링, 자세 전환 삽입, 깜빡임·귀 쫑긋, 기분에 따른 꼬리 속도, 시선 추적, 부위 판정을 검사합니다.

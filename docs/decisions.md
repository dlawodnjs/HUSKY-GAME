## 2026-10-23 · 디스코드 문구 수정안 전체 승인 · 적용 완료
- **사용자 결정:** 앞서 준비한 7개 수정안에 대해 "전부해줘"로 교체를 승인했다.
- **현재 구현:** 기존 안내글 7개를 승인안으로 교체하고 문구의 이모티콘을 제거했다. 구버전 설치 공지는 최신 다운로드 채널을 안내한다. 고정 상태 · 첨부 · 다운로드 버튼을 보존하고 재조회로 확인했다. 자동 게시 원본도 같은 문구로 맞췄다.
- **범위:** 안내글 본문과 임베드 제목을 수정했다. 채널 이름과 게임 기능 변경은 포함하지 않는다. 커밋 · 푸시는 하지 않았다.

## 2026-10-23 · 디스코드 안내글 문구 정리 (사용자 요청 · 교체 승인 대기)
- **사용자 결정:** 길고 AI가 쓴 듯한 설명글을 골라 자연스럽고 간결하게 다듬고, 사용자 확인을 받은 뒤 교체한다. 이모티콘도 제거한다.
- **현재 진행:** 안내글 · 설치 공지 7개의 원문과 수정안을 준비했다. 수정안 본문 · 임베드 제목의 이모티콘을 제거하고 채널 링크 표시 이름도 정리했다. 디스코드에는 아직 적용하지 않았다.
- **남은 일:** 사용자가 승인한 항목만 기존 글을 편집한다. 다운로드 안내처럼 도구가 다시 생성하는 글은 승인된 문구가 유지되도록 원본 양식도 맞춘다.

## 2026-10-23 · 디스코드 구역 열기 · 게시 도구를 이 저장소에 · 게임끼리 동등하게 (사용자 요청)
- **사용자 결정:** husky-puzzle `docs/discord-community.md` 3절대로 디스코드를 맞춘다. 이 게임 폴더에서도 디스코드 게시 · 편집을 할 수 있게 필요한 파일을 다 넣는다. 서버가 퍼즐 중심이 아니라 게임끼리 동등하게 보이게 하고, 나중에 게임을 더할 수 있게 문서를 둔다.
- **현재 구현:** 🐕 허스키 메이커 구역 · 채널 넷을 만들고 첫 업데이트 · 플레이 고정 글을 올렸다(2026-10-23). 게시 도구 `tools/discord_updates.py`(`status` · `sync` · `play`) · 검사 · 훅 파일 · [디스코드 안내](discord-updates.md). 중복 방지 기록은 이 저장소의 `.local/`(퍼즐 쪽 도구와 함께 씀). 게임 더하기 절차는 husky-puzzle의 `docs/discord-add-game.md`.
- **열린 것:** 플레이 주소(예: GitHub Pages). 이 저장소에 자동 게시 훅을 걸지(`install`).

# 허스키 썰매 협동: 3D 본 게임 (그레이박스)

기획서: [`../DESIGN.md`](../DESIGN.md)

## 실행
1. Godot **4.7** 이상을 설치합니다.
2. `husky-sled/game/project.godot`를 Import합니다.
3. F5로 실행합니다.

## 현재 단계: 기초 물리 (오프라인 혼자 테스트)
허스키 4마리 중 1마리를 조종합니다. 나머지 3마리는 개발용 봇입니다. 네트워크는 다음 단계에서 붙입니다.

| 키 | 동작 |
|---|---|
| WASD | 이동 (카메라 기준) |
| Shift | 달리기 (스태미나 소모) |
| Space | 점프 |
| 마우스 우클릭 누르고 이동 | 시야 회전 |
| Tab 누르고 있기 | 썰매 시점 |
| 1~4 | 조종할 허스키 바꾸기 (P1 좌 휠견, P2 좌 리더견, P3 우 휠견, P4 우 리더견) |
| B | 봇 모드: 가만히 있기 / 내 입력 따라하기 |
| R | 다시 시작 |

## 테스트 맵
시작 평원(나무, 점프대) → 좁은 절벽길(양옆이 공허) → 빙판 → 내리막 → 아래 평원의 도착 지점.
맵 밖은 바닥이 없어서, 허스키가 떨어지면 줄에 매달립니다.

## 구현된 물리
- 좌우 고리에 연결된 줄 4개 (휠견은 짧게, 리더견은 길게). 팽팽할 때만 당기고, 장력이 클수록 붉어짐
- 썰매는 앞뒤로 잘 미끄러지고 옆으로 드리프트. 빙판에서는 거의 안 멈춤
- 화물 6개 (아래 4개, 위 2개). 물리엔진으로만 떨어지고, 짐칸을 벗어나면 손상
- 허스키끼리, 허스키와 썰매가 부딪힘. 세게 부딪히면 넘어짐
- 점프, 달리기와 스태미나
- 절벽에서 떨어지면 줄에 매달리고, 동료가 반대로 당기면 끌어올려짐
- 브레이크 키 없음. 휠견이 뒤로 버티면 몸으로 썰매를 막아서 멈춤
- 화물이 모두 떨어지면 즉시 재시작, 도착하면 별점 표시

## 자동 테스트 결과 (Godot 4.7.2, 물리 120Hz)
| 상황 | 결과 |
|---|---|
| 4마리가 걸어서 4초 끌기 | 썰매 13.6m 이동, 화물 6/6 |
| 3마리 끌고 1마리 가만히 | 가만히 있던 허스키가 10.3m 끌려옴 |
| 4마리가 출발부터 달리기 | 화물 4/6 (급출발하면 위층 화물이 떨어짐) |
| 절벽에서 떨어짐 → 3마리가 달려서 구출 | 3.3m 아래에 매달렸다가 다시 땅 위로 올라옴 |
| 미끄러지는 썰매를 휠견 2마리가 뒤로 버팀 | 미끄러진 거리 13.2m → 11.5m |
| 달려오는 썰매에 치임 | 앞쪽 허스키들이 넘어짐 |

## 손맛 조절
`scripts/tuning.gd` 한 파일에 모든 수치가 있습니다. 예:
- `SLED_FORWARD_FRICTION`: 낮을수록 썰매가 더 미끄러움
- `ROPE_STIFFNESS`: 클수록 줄이 단단하지만, 팽팽해지는 순간 충격이 커서 화물이 잘 튐
- `IDLE_GRIP_FORCE`: 가만히 있는 허스키가 버티는 힘
- `CARGO_FRICTION`: 화물이 짐칸에서 버티는 정도

## 파일
```
scripts/main.gd        테스트 장면: 입력, 봇, 실패/도착 판정, HUD
scripts/husky.gd       허스키 (이동, 점프, 스태미나, 넘어짐, 매달림)
scripts/sled.gd        썰매 (미끄러짐, 빙판, 줄 고리)
scripts/rope.gd        줄 (단단한 줄, 장력 색)
scripts/cargo.gd       화물 (떨어짐 판정)
scripts/camera_rig.gd  카메라 (3인칭, Tab 썰매 시점, 우클릭 시야)
scripts/test_level.gd  물리 테스트 맵
scripts/tuning.gd      튜닝 값
```

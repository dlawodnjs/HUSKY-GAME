# 허스키 썰매 협동: 3D 본 게임 (그레이박스)

기획서: [`../DESIGN.md`](../DESIGN.md)

## 실행
1. Godot **4.7** 이상을 설치합니다.
2. `husky-sled/game/project.godot`를 Import합니다.
3. F5로 실행합니다.

## 현재 단계: 기초 물리 (오프라인 혼자 테스트)
허스키 4마리 중 1마리를 조종합니다. 나머지 3마리는 개발용 봇입니다. 네트워크는 다음 단계에서 붙입니다.

| 키 | 동작 |
|---|---|
| WASD | 이동 (카메라 기준) |
| Shift | 달리기 (스태미나 소모) |
| Space | 점프 |
| 마우스 우클릭 누르고 이동 | 시야 회전 |
| Tab 누르고 있기 | 썰매 시점 |
| 1~4 | 조종할 허스키 바꾸기 (P1 좌 휠견, P2 좌 리더견, P3 우 휠견, P4 우 리더견) |
| B | 봇 모드: 가만히 있기 / 내 입력 따라하기 |
| R | 다시 시작 |
| L | 다음 맵 (물리 테스트 맵 ↔ 세 갈래 길) |

## 맵 (L 키로 바꿈)
맵 밖은 바닥이 없어서, 허스키가 떨어지면 줄에 매달립니다.

### 1-4 세 갈래 길 (기본 시작 맵)
```
 시작 평원 → [ 왼쪽 길 | 가운데 길(썰매 전용) | 오른쪽 길 ] → 합류 → 다리 → 도착 평원
```
- **가운데 길**은 폭 2.2m의 평평한 길이고 **썰매 전용**입니다. 입구와 칸막이 위에 반투명한 파란 막이 있어서 썰매와 화물은 지나가지만 **허스키는 못 들어갑니다.** 중간에 빙판이 있습니다.
- **왼쪽 길**(좌 휠견, 좌 리더견)과 **오른쪽 길**(우 휠견, 우 리더견)은 구멍이 뚫려 있습니다.
  - 왼쪽 구멍 4.2m: 달리면서 점프
  - 오른쪽 구멍 5.0m: 점프대에서 달리면서 점프
  - 구멍 맞은편 아래에 폭 0.6m의 낮은 선반이 있어서, 아깝게 못 건넌 허스키는 점프로 올라올 수 있습니다. 크게 빗나가면 공허로 떨어져서 줄에 매달립니다.
- 두 길이 합쳐지는 지점을 지나면 난간이 낮은 다리가 나오고, 그 뒤가 도착 평원입니다.
- **네 마리가 앞으로만 걸어서는 클리어할 수 없습니다.** 막에 걸립니다. 팀이 양쪽으로 갈라져서, 구멍 앞에서 같이 달려야 합니다.
- 줄이 짧은 휠견은 썰매에서 멀리 못 떨어지므로, **썰매가 같이 빠르게 달려야** 구멍을 건널 수 있습니다. (썰매를 끌고 달릴 때 팀 속도는 약 5~6m/s)

### 물리 테스트 맵
시작 평원(나무, 점프대) → 좁은 절벽길(양옆이 공허) → 빙판 → 내리막 → 아래 평원의 도착 지점.

## 구현된 물리
- 좌우 고리에 연결된 줄 4개 (휠견은 짧게, 리더견은 길게). 팽팽할 때만 당기고, 장력이 클수록 붉어짐
- 썰매는 앞뒤로 잘 미끄러지고 옆으로 드리프트. 빙판에서는 거의 안 멈춤
- 화물 6개 (아래 4개, 위 2개). 물리엔진으로만 떨어지고, 짐칸을 벗어나면 손상
- 허스키끼리, 허스키와 썰매가 부딪힘. 세게 부딪히면 넘어짐
- 점프, 달리기와 스태미나
- 절벽에서 떨어지면 줄에 매달리고, 동료가 반대로 당기면 끌어올려짐
- 브레이크 키 없음. 휠견이 뒤로 버티면 몸으로 썰매를 막아서 멈춤
- 화물이 모두 떨어지면 즉시 재시작, 도착하면 별점 표시

## 자동 테스트 결과 (Godot 4.7.2, 물리 120Hz)
실행 방법과 기대 결과 전체는 [`tests/README.md`](tests/README.md)에 있습니다.

**물리 테스트 맵**
| 상황 | 결과 |
|---|---|
| 4마리가 걸어서 4초 끌기 | 썰매 13.6m 이동, 화물 6/6 |
| 3마리 끌고 1마리 가만히 | 가만히 있던 허스키가 10.3m 끌려옴 |
| 4마리가 출발부터 달리기 | 화물 4/6 (급출발하면 위층 화물이 떨어짐) |
| 절벽에서 떨어짐 → 3마리가 달려서 구출 | 3.3m 아래에 매달렸다가 다시 땅 위로 올라옴 |
| 미끄러지는 썰매를 휠견 2마리가 뒤로 버팀 | 미끄러진 거리 13.0m → 11.3m |
| 달려오는 썰매에 치임 | 앞쪽 허스키들이 넘어짐 |

**세 갈래 길**
| 상황 | 결과 |
|---|---|
| 네 마리가 앞으로만 걷기 | 입구 막에 걸려서 전진 못 함 |
| 양쪽 길로 갈라져서 구멍 앞에서 같이 달리고 점프 | 화물 6/6, 약 23초에 도착 |
| 한 팀만 달리기 | 도착 (화물 5~6/6) |
| 아무도 달리지 않음 | 도착하지만 화물 5/6 |

## 손맛 조절
`scripts/tuning.gd` 한 파일에 모든 수치가 있습니다. 예:
- `SLED_FORWARD_FRICTION`: 낮을수록 썰매가 더 미끄러움
- `ROPE_STIFFNESS`: 클수록 줄이 단단하지만, 팽팽해지는 순간 충격이 커서 화물이 잘 튐
- `IDLE_GRIP_FORCE`: 가만히 있는 허스키가 버티는 힘
- `CARGO_FRICTION`: 화물이 짐칸에서 버티는 정도

## 파일
```
scripts/main.gd        테스트 장면: 입력, 봇, 맵 전환, 실패/도착 판정, HUD
scripts/husky.gd       허스키 (이동, 점프, 스태미나, 넘어짐, 매달림)
scripts/sled.gd        썰매 (미끄러짐, 빙판, 줄 고리)
scripts/rope.gd        줄 (단단한 줄, 장력 색)
scripts/cargo.gd       화물 (떨어짐 판정)
scripts/camera_rig.gd  카메라 (3인칭, Tab 썰매 시점, 우클릭 시야)
scripts/level_base.gd   맵 공통 도구 (땅, 벽, 경사로, 빙판 표시, 썰매 전용 막, 나무, 도착 깃발)
scripts/test_level.gd  물리 테스트 맵
scripts/lane_level.gd  1-4 세 갈래 길
scripts/tuning.gd      튜닝 값
```

## 맵을 만들 때 알아둘 것
- 새 맵은 `level_base.gd`를 extends 하고, `_init()` 맨 위에서 **`super()`를 호출**해야 합니다. 빼먹으면 땅 마찰이 0이 아니라 1.0이 되어서 썰매와 화물 동작이 전부 달라집니다.
- 땅을 상자 여러 개로 이어 붙이면 이음매에 썰매 모서리가 걸릴 수 있습니다. 썰매 날을 둥근 캡슐로 만들어서 해결했고, 맵에서도 이음매 위에 높이 차이를 만들지 마세요.
- 빙판은 높이가 있는 상자가 아니라 `_ice_patch()`(충돌 없는 평평한 표시)로 만드세요. 상자로 만들면 4cm 턱에 썰매가 걸립니다.
- 구멍 위에 칸막이나 막을 띄워 두지 마세요. 매달린 허스키가 그 밑으로 끌려 들어가서 끼입니다. 구멍 아래까지 이어지는 벽으로 만드세요.
- 줄이 짧은 휠견이 썰매와 같이 움직여야 하므로, 구멍 폭은 5m 이하로 하세요.

# 허스키 썰매 협동 (Husky Sled Co-op)

플레이어 한 명이 허스키 한 마리를 맡아서, **아주 미끄러운 썰매**를 함께 끌고 목적지까지 배달하는 협동 게임입니다.
Godot 4.3 이상으로 만들었습니다.

## 실행 방법
1. [Godot 4.3+](https://godotengine.org/download)를 설치합니다. 표준 버전이면 되고, .NET 버전은 필요 없습니다.
2. Godot에서 **Import**를 누르고 이 폴더의 `project.godot`를 엽니다.
3. F5로 실행합니다.

### 메뉴
| 버튼 | 설명 |
|---|---|
| Local 2P | 한 키보드로 2명이 플레이 |
| Solo test | 혼자서 손맛 테스트 |
| Host online game | 내 컴퓨터가 간이 서버(호스트)가 됨. 친구는 내 IP로 접속 |
| Join | 호스트의 IP를 입력하고 접속 |

### 조작
| | 이동 | 브레이크 | 같이 당기기 |
|---|---|---|---|
| 로컬 P1 | WASD | Q | E |
| 로컬 P2 | IJKL | U | O |
| 온라인/솔로 | WASD 또는 방향키 | Q 또는 Shift | E 또는 Space |

## 협동 규칙 (현재 구현된 것)
- **힘의 합**: 썰매는 줄에 걸린 힘의 합으로 움직입니다. 서로 다른 방향으로 당기면 힘이 상쇄됩니다.
- **미끄러운 썰매**: 앞뒤로 잘 미끄러지고 옆으로도 드리프트합니다. **빙판(ICE)** 위에서는 거의 멈추지 않습니다.
- **역할**
  - `WHEEL`(썰매 바로 앞): 유일하게 **브레이크**를 걸 수 있습니다.
  - `LEAD`(맨 앞, 3인 이상일 때): 당기는 힘이 15% 더 셉니다.
  - `SWING`(중간): 일반 역할입니다. 5인 이상부터 생기므로 현재 최대 4인에서는 나오지 않습니다.
- **같이 당기기**: 연결된 모든 플레이어가 0.4초 안에 함께 누르면 썰매가 확 튀어나갑니다.
- **나무**: 나무 양쪽으로 갈라지면 썰매가 나무에 걸립니다.
- 플레이어가 늘면 허스키가 2마리씩 한 줄로 앞에 붙고, 줄은 더 길어집니다.

## 온라인 플레이 (호스트 방식)
- 호스트 컴퓨터만 물리를 계산하고, 다른 사람은 키 입력만 보내고 결과를 받아서 보여줍니다.
- 같은 공유기(LAN)라면 로비에 표시되는 IP로 바로 접속할 수 있습니다.
- 인터넷 너머의 친구와 하려면 지금은 호스트가 **UDP 7777 포트포워딩**을 해야 합니다.
  이 문제는 나중에 Steam 연동(GodotSteam)을 하면 사라집니다. 아래 로드맵 참고.
- 한 PC에서 테스트하는 방법: Godot 메뉴 `Debug > Customize Run Instances`에서 인스턴스를 2개로 늘리고,
  각각 인자로 `--host`, `--join=127.0.0.1`을 넣으면 실행과 동시에 연결됩니다.

## 파일 구조
```
scenes/main.tscn   메인 씬 (스크립트만 붙어 있음)
scripts/main.gd    메뉴, 로비, 결과 화면, 접속 흐름
scripts/net.gd     네트워크 연결 생성 (Steam으로 바꿀 때 이 파일만 교체)
scripts/game.gd    게임 본체: 입력 전송, 서버 물리, 줄, 상태 동기화, HUD
scripts/level.gd   코스 (중심선 점 목록 → 벽, 나무, 빙판, 도착점)
scripts/sled.gd    썰매
scripts/husky.gd   허스키
```

## 손맛 조절
`scripts/game.gd` 맨 위의 튜닝 값만 바꿔도 느낌이 크게 달라집니다.
- `SLED_DAMP`: 낮을수록 관성이 커집니다 (더 미끄러움).
- `SLED_SIDE_GRIP`: 낮을수록 옆으로 드리프트가 심해집니다.
- `HUSKY_PULL_FORCE`, `ROPE_K`, `SYNC_IMPULSE` 등.

코스는 `scripts/level.gd`의 `CENTERLINE`, `TREES`, `ICE` 목록을 고치면 바뀝니다.

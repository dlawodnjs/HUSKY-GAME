# 허스키 메이커 — 교감 샌드박스 (Godot 프로토타입 1차)

회색 방과 도형으로 만든 아기 허스키, 그리고 내 손이 된 마우스 커서만 있는 프로토타입입니다.
목표는 하나입니다. **손으로 만지면 진짜 개처럼 반응하는가.**
하루 흐름·스탯·세이브는 다음 마일스톤에서 붙입니다.

## 실행

1. [Godot 4](https://godotengine.org/download) 표준 버전을 설치합니다(4.7.2에서 테스트). .NET 버전은 필요 없습니다.
2. Godot 프로젝트 매니저에서 **가져오기** → 이 폴더의 `project.godot`을 선택합니다.
3. F5로 실행합니다. 커서가 손 모양으로 바뀝니다. Esc를 누르면 OS 커서를 다시 볼 수 있습니다.

렌더러는 `Compatibility`(OpenGL 3)입니다. 저사양 PC와 Steam Deck에서도 돌고, 헤드리스 검증도 쉽습니다.

## 조작

| 손짓 | 방법 | 허스키가 하는 일 |
| --- | --- | --- |
| 쓰다듬기 | 허스키 위에서 누른 채 문지르기 | 부위·결 방향·신뢰에 따라 기대거나, 눈을 감거나, 몸을 털고 피함 |
| 긁어 주기 | 누른 채 작은 원 그리기 | 턱·귀 뒤·엉덩이가 좋으면 뒷다리가 저절로 차짐 |
| 손 내밀기 | 빈 손을 머리 앞에 가만히 | 처음엔 냄새만, 친해지면 부비거나 핥거나 손을 줌 |
| 안아 올리기 | 등·배·엉덩이를 누른 채 0.4초 멈췄다가 위로 | 아기일 때만 가능. 성견(F2)이면 무거워서 실패 |
| 간식 | `2` 또는 휠로 간식 들기 → 머리 위로 올리기 → 앉으면 클릭 | 코가 손을 따라오고, 머리 위로 들면 앉음. **앉은 뒤 1초 안에** 줘야 '앉아'를 배움 |
| 손 신호 '앉아' | 빈 손을 머리 위로 들고 가만히 | 숙련도 50%부터 간식 없이 앉음 |
| "앉아!" | 화면 아래 버튼 | 숙련도 100%부터 말로만 앉음. 그래도 가끔 못 들은 척 |
| 부르기 | 빈 곳 더블클릭(손뼉) 또는 "이름 부르기" | 유대가 높을수록 달려옴. 낮으면 귀만 쫑긋 |
| 공 | 바닥의 공 클릭 → 위로 드래그해 놓기 | 물어 오기를 배우기 전엔 물고 도망. 할수록 가져오는 확률 상승 |
| 가리키기 | 바닥 우클릭 | 이해하면 그곳으로 가서 냄새를 맡고, 아니면 손가락만 봄 |
| 안 돼! | Space | 슬리퍼를 씹거나 우다다 중일 때 2.5초 안이면 효과. 늦거나 이유 없이 혼내면 신뢰만 떨어지고 움찔하게 됨 |

| 키 | 기능 |
| --- | --- |
| `1` `2` `3` / 휠 | 빈 손 · 간식 · 공 |
| F1 | 숨은 값 패널: 유대·신뢰·욕구·숙련도·좋아하는 부위(비밀)·입력→반응 지연 |
| F2 | 아기 ↔ 성견 크기 전환 (안아 올리기 실패 확인용) |

가만히 두면 스스로 행동합니다. 배회, 냄새 맡기, 낮잠(방석), 관심 끌기(카메라 앞에 와서 앉아 쳐다보기), 공 물어 오기, 우다다, 하울링, 슬리퍼 씹기 중에서 그때의 욕구에 맞는 것을 고릅니다.
그 사이사이 하품·몸 털기·창밖 보기·꼬리 쫓기 같은 작은 순간이 끼어듭니다. 소리 대신 머리 위 말풍선(의성어)으로 표현합니다.

## 이번 샌드박스로 확인할 것

기획안의 '매끄러움 품질 기준'을 직접 손으로 검수합니다.

- [ ] 손을 움직이면 시선과 귀가 바로 따라오는가 (F1의 입력→반응 지연이 100ms 미만인가)
- [ ] 어떤 반응 도중에 다른 손짓을 해도 뚝 끊기지 않고 이어지는가
- [ ] 같은 곳을 계속 쓰다듬어도 반응이 반복적으로 느껴지지 않는가
- [ ] 좋아하는 부위를 스스로 찾아내는 재미가 있는가
- [ ] 간식으로 '앉아'를 가르치는 과정이 진짜 훈련처럼 느껴지는가
- [ ] 할 일이 없어도 방에 머물며 만지고 싶어지는가

## 구조

| 경로 | 역할 |
| --- | --- |
| `scripts/main.gd` | 방·조명·카메라를 만들고 허스키·손·HUD를 연결 |
| `scripts/husky/husky.gd` | 몸 조립, 자세 레이어, 행동 실행, 손짓 반응 API |
| `scripts/husky/brain.gd` | 유틸리티 AI (욕구 → 행동 점수 → 이력 있는 전환) |
| `scripts/husky/bond.gd` | 유대·신뢰, 부위 선호와 손 습관, 기억, 명령어 숙련도 |
| `scripts/husky/reactions.gd` | 반응 변주 풀, 연속 반복 금지 |
| `scripts/husky/look_at.gd` | 목·머리 시선 추적 |
| `scripts/hand/hand.gd` | 마우스 → 3D 레이캐스트, 손에 든 것, 손짓 → 허스키 호출 |
| `scripts/hand/gesture_recognizer.gd` | 쓰다듬기·긁기·멈춤·더블클릭 판정 (순수 로직) |
| `scripts/hand/hand_cursor_2d.gd` | 손 커서 그리기 |
| `scripts/toys/ball.gd` | 공 (손·바닥·입 세 가지 상태) |
| `scripts/ui/hud.gd` | 손 툴바, 음성 명령 버튼, 알림, F1 디버그 패널 |
| `tests/run_tests.gd` | 단위 테스트 + 메인 씬 헤드리스 시나리오 |

회색 박스 노드는 스크립트에서 만듭니다. 손으로 쓴 `.tscn`이 깨질 위험을 줄이고, 나중에 실제 모델로 바꿀 때 `husky.gd`의 `_build_body()`만 교체하면 되게 하기 위해서입니다.

## 테스트

```sh
godot --headless --path godot --import
godot --headless --path godot --fixed-fps 60 -s res://tests/run_tests.gd
```

손짓 인식, 유틸리티 AI, 유대·신뢰, '앉아' 학습 단계, 반응 변주를 검사한 뒤 메인 씬을 900프레임 돌리며 부르기·쓰다듬기·긁기·간식·안아 올리기·공 던지기·혼내기·가리키기를 차례로 호출합니다. 실패가 있으면 종료 코드 1입니다.

## 스크린샷 찍기

에디터 없이 주요 장면(대기, 쓰다듬기, 간식으로 앉히기, 안아 올리기, 잠, 성견+디버그 패널)을 PNG로 저장합니다. 디스플레이가 없는 서버에서는 Xvfb를 씁니다.

```sh
xvfb-run -s "-screen 0 1280x720x24" godot --path godot --rendering-driver opengl3 \
  --fixed-fps 60 -s res://tools/capture_screens.gd -- --out=/tmp/shots
```

F1 패널의 '입력→반응'은 입력이 들어온 순간부터 허스키가 다음 물리 프레임에서 반응을 적용하기까지의 실제 시간입니다. 60fps에서 한 프레임(약 17ms) 안쪽이 정상이고, 느린 소프트웨어 렌더링에서는 더 크게 나옵니다.
